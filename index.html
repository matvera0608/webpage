TESIS / SISTEMA ACADÉMICO 2025

Sistema de Gestión de Asistencia Escolar

Control ABM & Procesamiento ETL con Python & MySQL

Proyecto Desarrollado

Software modularizado para la administración integral de instituciones educativas. Incluye control de roles, operaciones ABM optimizadas con bases de datos relacionales, validación inteligente de archivos de importación como TXT, CSV, XLSX y exportación automatizada de reportes en PDF. Además, cuenta con un sistema de procesamiento ETL para la gestión escolar, permitiendo la eficiencia en la carga de datos académicos. Utiliza Python con Tkinter para la interfaz de usuario y MySQL como motor de base de datos relacionales.

Python Tkinter / UI MySQL Pandas / ETL

SOFTWARE UTILITY v1.4

Calculadora Multifuncional

Lógica matemática · Algoritmos de conversión

Proyecto Desarrollado

Esta es una calculadora científica simple pero multifuncional, además está en constante mejora. Tiene una interfaz gráfica hecha con Tkinter y utiliza ventanas secundarias Toplevels para mostrar funciones avanzadas de conversión y cálculo a partir de la interfaz principal. Las funciones son:

  • Cálculos aritméticos básicos incluyendo raíces enésimas.
  • Conversión de divisas como pesos argentinos, dólares, reales, guaranís y euros.
  • Tabla de multiplicar y de dividir.
  • Detección de números primos y compuestos.
